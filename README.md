# Clack

一个简单的中英文打字练习应用：选一篇文章，逐行练习并实时查看对错，完成后回顾错字、速度和准确率。中文、英文历史分别统计，支持 JSON 导入和导出。

## 添加到熊猫小抽屉

在熊猫小抽屉的推荐列表选择 Clack，或在「添加应用 › 有应用链接」粘贴本仓库链接。已有下载文件夹时，选择包含 `panda.json` 的根目录添加。需要准备网页时，按平台提示完成准备后打开。

本应用使用 `panda.json` v2，无后台，通过平台 SDK 将练习历史和设置保存到本机 `data/main.sqlite`。首次打开会自动准备数据库结构，不需要手动初始化。

## 配置和费用

无需账号、API Key 或额外付费服务，运行不访问第三方统计、广告或在线文章接口。

## 使用

- 选择中文或英文文章，按篇幅、分类筛选；输入框会逐行校验，支持中文输入法。
- `Esc` 暂停，`⌘/Ctrl + Enter` 重新开始。
- 完成后查看速度、准确率和错字；也可以只练错字，这部分不计入历史。
- 历史页查看练习记录，按需导出备份。

## 用自己的 AI 修改

在应用窗口点「按你的想法改」，把需求告诉自己的 AI。修改后点「重新加载」查看结果。代码版本由 Git 管理，删除数据前需先确认；Git 不能代替数据备份。
