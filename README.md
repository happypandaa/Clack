# Clack

一个简单的中英文打字练习应用。使用原生 HTML、CSS 和 JavaScript，运行于熊猫小抽屉的网页应用环境，通过平台 SDK（`/_platform/sdk.js` 提供的 `window.panda`）保存本地 SQLite 数据。

## 功能

- **选文章**：内置中文、英文各 6 篇文章，支持搜索与筛选；界面语言与文章语言独立切换。
- **打字练习**：整篇文章逐行展示，每行原文下方是对应输入行，实时标记对错；满行自动进入下一行，支持中文输入法批量上屏。
- **跟随输入**：长文章在换行时将当前输入行尽量保持在窗口中央，支持减少动态效果的系统偏好。
- **历史记录**：中文、英文分别统计，支持 JSON 导入、导出。中文速度按正确汉字/分钟，英文按每 5 个正确字符折算 WPM。
- **可靠保存**：暂停、失焦时停止计时；成绩保存失败时可重试或导出，应用更新需要手动重新加载。

## 运行环境

运行时使用平台提供的原生窗口、SQLite 和项目会话，无 Node 应用后端，无额外账号或在线 API。Node.js 只用于开发、测试和构建。

本仓库是**网页应用源码项目**，通过根目录的 `panda.json` 声明类型（`runtime: web`）、网页入口和构建脚本。直接双击 HTML、打开 Vite 地址或部署至 GitHub Pages 无法提供平台数据库和会话。

## 开发与验证

需要 Node.js `^22.12.0` 或 `^24.0.0` 和 pnpm。

```sh
cd app
pnpm install
pnpm test
pnpm run build
```

本地构建产物为 `app/dist/`。平台按 `panda.json` 的 `development.build` 执行 `npm run build`，产物位置以 `web.root` 为准。构建过程不会初始化或修改数据库。

## 接入自己的平台项目

1. 在熊猫小抽屉点「添加应用」，粘贴本应用链接；已有本机源码时，选「本机文件夹」并选择包含 `panda.json` 的本仓库根目录。
2. 需要准备网页时，按提示完成准备，再打开应用。首次打开会通过平台 SDK 事务自动准备数据库结构，保留已有结构和练习记录，不需要手工执行初始化命令。
3. 初始化失败时，应用会显示错误并允许重试，不清空数据库。平台规则见熊猫小抽屉随附的 skill。

## 文件结构

| 路径 | 内容 |
| --- | --- |
| `app/web/` | 页面、样式、内置文章、打字逻辑、全文输入行及存储适配 |
| `app/tests/` | 打字、渲染和平台存储的隔离测试 |
| `app/db/schema.sql` | 数据库初始化 DDL，无练习数据 |
| `docs/database.md` | 表结构、统计单位和读写约定 |
| `docs/platform.md` | 平台 SDK 接口与运行约束 |
| `panda.json` | 应用类型、网页入口和构建声明 |

## 数据与隐私

练习历史和设置保存在用户自己的平台项目数据库中。应用未接入第三方统计、遥测、广告或在线文章服务，运行不访问外部 API。JSON 导出只在用户操作时生成，文件的分享由用户自行决定。

本仓库仅包含经过检查的源码、合成测试样本、数据库结构和固定 SDK。未包含实际数据库、练习记录、附件、环境配置、访问凭据、本机绝对路径、个人开发日志或原项目的 Git 提交历史。公开提交使用 GitHub 隐私邮箱。

中文输入法真实候选交互、移动设备与原生导入导出对话框仍需在目标环境验证，自动测试不替代这些场景。
